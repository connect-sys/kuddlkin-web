== Overview
// ============================================================

Adobe Workfront exposes a RESTful HTTP API — historically referred to as the **attask** API — that lets you programmatically manage *Projects*, *Tasks*, *Issues*, *Users*, *Documents*, *Portfolios*, and many other Workfront objects.

[NOTE]
====
This document is generated from the OpenAPI 3.0 specification (`workfront-openapi.yaml`).
The specification targets **API version {version}**.
====

=== Base URL

[source]
----
https://{domain}.workfront.com/attask/api/v21.0
----

[cols="1,3", options="header"]
|===
| Variable | Description
| `{domain}` | Your Workfront company subdomain (e.g., `acmecorp`)
|===

.Sandbox / Preview environment
[source]

=== Supported HTTP Methods

[cols="1,2,4", options="header"]
|===
| Method | Operation | Notes
| `GET` | Retrieve objects | Search or fetch by ID
| `POST` | Create objects | Body must be JSON
| `PUT` | Update objects | Partial updates supported
| `DELETE` | Delete objects | Some objects require `force=true`
|===

TIP: For HTTP clients that only support `GET` and `POST`, append `&method=PUT` or `&method=DELETE` to the query string.

=== Response Envelope

All responses are wrapped in a standard JSON envelope:

[source,json]
----
{
  "data": { ... }          // single object
}
// or
{
  "data": [ ... ]          // collection
}
// or
{
  "error": {
    "message": "...",
    "class": "...",
    "msgKey": "..."
  }
}
----

== Authentication
// ============================================================

Workfront supports two authentication strategies:

=== Session-based Authentication

. Call `POST /login` with `username` and `password`.
. Capture the `sessionID` from the response.
. Pass `sessionID` as a query parameter on every subsequent request.
. Terminate the session with `GET /logout`.

.Login request example
[source,bash]
----
curl -X POST \
  "https://acmecorp.workfront.com/attask/api/v21.0/login?username=admin@acme.com&password=secret"
----

.Login response
[source,json]
----
{
  "data": {
    "sessionID": "abc123def456",
    "userID": "5cf0415a009ec7f654918e8ae696aab9"
  }
}
----

=== API Key Authentication

. Retrieve your API key via `GET /user/getApiKey`.
. Pass `apiKey=<key>` as a query parameter instead of `sessionID`.

[source,bash]
----
curl "https://acmecorp.workfront.com/attask/api/v21.0/project?apiKey=mykey&fields=name,status"
----

---

==== `POST /login`

Authenticate and obtain a session token.

[cols="1,3", options="header"]
|===
| Parameter | Description
| `username` _(required)_ | Workfront login email or username
| `password` _(required)_ | User password
|===

[cols="1,3", options="header"]
|===
| Response Code | Meaning
| `200` | Login successful — body contains `sessionID` and `userID`
| `401` | Invalid credentials
|===

---

==== `GET /logout`

Terminates the current session.

[cols="1,3", options="header"]
|===
| Parameter | Description
| `sessionID` _(required)_ | Active session token
|===

---

==== `GET /user/getApiKey`

Returns the API key for the authenticated user.

== Common Query Parameters
// ============================================================

The following parameters apply to most `GET` and `POST` requests.

[cols="1,1,4", options="header"]
|===
| Parameter | Type | Description
| `sessionID` | string | Active session token
| `apiKey` | string | API key (alternative to sessionID)
| `fields` | string | Comma-separated field names to include in the response. Use `*` for all fields, prefix `!` to exclude.
| `$$LIMIT` | integer | Maximum records returned (default `100`, max `2000`)
| `$$FIRST` | integer | Zero-based offset for pagination (default `0`)
| `method` | string | HTTP method override: `GET`, `POST`, `PUT`, `DELETE`
|===

.Pagination example
[source,bash]
----
GET /project?sessionID=abc&$$LIMIT=50&$$FIRST=100
----

.Field selection example
[source,bash]
----
GET /project/{ID}?sessionID=abc&fields=name,status,percentComplete,owner:name
----

==== `GET /project` — List Projects

Search or list all projects accessible to the authenticated user.

[cols="1,1,1,4", options="header"]
|===
| Parameter | Type | Required | Description
| `sessionID` | string | Yes | Session token
| `status` | string | No | Filter by status code (`CUR`, `PLN`, etc.)
| `name` | string | No | Filter by name; supports `*` wildcards
| `ownerID` | string | No | Filter by owner User ID
| `$$LIMIT` | integer | No | Max records (default 100)
| `$$FIRST` | integer | No | Pagination offset
| `fields` | string | No | Fields to return
|===

.Example — list active projects
[source,bash]
----
curl "https://acme.workfront.com/attask/api/v21.0/project \
  ?sessionID=abc \
  &status=CUR \
  &fields=name,status,percentComplete,plannedCompletionDate"
----

.Response
[source,json]
----
{
  "data": [
    {
      "ID": "5cf0415a009ec7f654918e8ae696aab9",
      "name": "Website Redesign Q3",
      "status": "CUR",
      "percentComplete": 45.0,
      "plannedCompletionDate": "2024-06-30T17:00:00:000-0500"
    }
  ]
}
----

== Filtering & Sorting
// ============================================================

=== Filter Operators

Append operators to field names in the query string:

[cols="1,3,3", options="header"]
|===
| Suffix | Operator | Example
| _(none)_ | Equals | `status=CUR`
| `_Mod=in` | In list | `status=CUR&status_Mod=in`
| `_Mod=notin` | Not in list | `status=CPL&status_Mod=notin`
| `_Mod=contains` | Contains (string) | `name=Marketing&name_Mod=contains`
| `_Mod=notcontains` | Does not contain | —
| `_Mod=gte` | Greater than or equal | `percentComplete=50&percentComplete_Mod=gte`
| `_Mod=lte` | Less than or equal | —
| `_Mod=between` | Between two values | —
| `_Mod=isblank` | Field is null/empty | —
| `_Mod=notblank` | Field is not null | —
|===

=== Sorting

[cols="1,3", options="header"]
|===
| Parameter | Description
| `$$SORT` | Field to sort by (e.g., `$$SORT=plannedCompletionDate`)
| `$$DIRECTION` | `asc` (ascending) or `desc` (descending, default)
|===

=== cURL — Complete workflow

.Step 1: Login
[source,bash]
----
SESSION=$(curl -s -X POST \
  "https://acme.workfront.com/attask/api/v21.0/login?username=admin@acme.com&password=secret" \
  | jq -r '.data.sessionID')
----

.Step 2: Create a project
[source,bash]
----
PROJECT_ID=$(curl -s -X POST \
  "https://acme.workfront.com/attask/api/v21.0/project?sessionID=$SESSION" \
  -H "Content-Type: application/json" \
  -d '{"name":"Q4 Campaign","plannedStartDate":"2024-10-01T08:00:00.000Z"}' \
  | jq -r '.data.ID')
----

.Step 3: Create a task in the project
[source,bash]
----
curl -s -X POST \
  "https://acme.workfront.com/attask/api/v21.0/task?sessionID=$SESSION" \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Kickoff Meeting\",\"projectID\":\"$PROJECT_ID\",\"duration\":1,\"durationUnit\":\"D\"}"
----

.Step 4: Logout
[source,bash]
----
curl "https://acme.workfront.com/attask/api/v21.0/logout?sessionID=$SESSION"
----

=== JavaScript (Fetch API)

[source,javascript]
----
const BASE = 'https://acme.workfront.com/attask/api/v21.0';

async function login(username, password) {
  const res = await fetch(`${BASE}/login?username=${username}&password=${password}`, {
    method: 'POST'
  });
  const { data } = await res.json();
  return data.sessionID;
}

async function getProjects(sessionID) {
  const res = await fetch(
    `${BASE}/project?sessionID=${sessionID}&status=CUR&fields=name,status,percentComplete&$$LIMIT=50`
  );
  const { data } = await res.json();
  return data;
}

async function createTask(sessionID, projectID, taskName) {
  const res = await fetch(`${BASE}/task?sessionID=${sessionID}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name: taskName, projectID })
  });
  return (await res.json()).data;
}
----

=== Python (requests)

[source,python]
----
import requests

BASE = "https://acme.workfront.com/attask/api/v21.0"

def login(username, password):
    r = requests.post(f"{BASE}/login", params={"username": username, "password": password})
    return r.json()["data"]["sessionID"]

def search_projects(session_id, **filters):
    params = {"sessionID": session_id, "fields": "*", **filters}
    r = requests.get(f"{BASE}/project", params=params)
    return r.json()["data"]

def update_task(session_id, task_id, **fields):
    params = {"sessionID": session_id}
    r = requests.put(f"{BASE}/task/{task_id}", params=params, json=fields)
    return r.json()["data"]

# Usage
session = login("admin@acme.com", "secret")
projects = search_projects(session, status="CUR")
for p in projects:
    print(p["name"], p.get("percentComplete"))
----
